# ScholarOne Integration Plugin

This plugin integrates OPS and ScholarOne, ingesting preprints from OPS into the ScholarOne plataform.

## Compatibility

The latest release of this plugin is compatible with the following PKP applications:

* OPS 3.4.0

## Plugin Download

To download the plugin, go to the [Releases page](https://github.com/lepidus/scholarOneIntegration/releases) and download the tar.gz package of the latest release compatible with your website.

## Installation

1. Enter the administration area of ​​your OPS website through the __Dashboard__.
2. Navigate to `Settings`>` Website`> `Plugins`> `Upload a new plugin`.
3. Under __Upload file__ select the file __scholarOneIntegration.tar.gz__.
4. Click __Save__ and the plugin will be installed on your website.
